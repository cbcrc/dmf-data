# Network and transport

Studies of moving media between hosts: RDMA, MXL fabrics, network cards, ST 2110, and time synchronisation (PTP).

- [Moving MXL video between servers over RDMA](2026-10-rdma-grain-transit/) (September-October 2026): a 1080p
  grain crosses to another server in about 0.7 ms over RDMA (Verbs), five times faster and far steadier than TCP,
  with no loss on either.
